# Lead Saver - Save Leads to CSV

A lightweight, local-first Manifest V3 Chrome extension to save prospects from any webpage—Google Maps, LinkedIn, company websites, or directories—with quick notes and export your list to CSV.

## Features

- **One-Click Lead Capture:** Prefills the active page title and URL with an editable lead name and multi-line notes.
- **Auto-Detected Source:** Automatically tags each saved lead as `Maps`, `LinkedIn`, or `Website`.
- **Mini Lead Database:** Click any saved lead in the popup to reopen its URL in a new tab, or revisit a saved page to update notes without creating duplicates.
- **Spreadsheet-Safe CSV Export:** Downloads `lead-saver-YYYY-MM-DD.csv` with proper CSV escaping and formula-injection protection.
- **100% Local & Private:** Uses only `activeTab` and `storage`. Zero accounts, zero backend servers, zero tracking.
